Small models can be wrong

This model is tiny on purpose, so it fits in a browser. It can misread a question, miss a fact that is plainly written, or sound sure when it is not. Two plain-rule checks (no AI) back it up: one skips the model and hands off when nothing in the facts matches the question, and one swaps in a hand-off line when a reply uses a number that is not in the facts. The scripted test results below show how often it still slips. Treat this as a first-line answer, not a replacement for a person.

What is running

  • Model: Qwen2.5 1.5B Instruct (Apache 2.0), 4-bit, about 880 MB, run through the open source web-llm library (Apache 2.0).
  • Where it comes from: model files from Hugging Face and the compiled GPU program from GitHub, both public with no account. Your browser keeps them after the first load.
  • Instant mode: without WebGPU, or before you load the model, a simple keyword lookup answers instead. It is not AI and it is labeled that way.
